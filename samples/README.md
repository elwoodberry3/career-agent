# Sample job descriptions

Paste real job postings here as `.txt` files to tune the scorer
(`python scripts/score_samples.py`).

Optional first line: `Title | Company | Location`. The rest is the description.

Aim for a mix:
- 2–3 you'd apply to today
- 2–3 obvious misses (wrong level, wrong field, dealbreaker)
- 2–3 traps: keyword-heavy but wrong in a way that matters

Name them so the expected answer is obvious, e.g. `great_ai-director_acme.txt`,
`miss_sales-commission.txt`, `trap_junior-title-senior-keywords.txt`.

Postings are other companies' text. Keep them out of the public repo if you
prefer: `samples/*.txt` is gitignored by default.
